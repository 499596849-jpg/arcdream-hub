# v0.1.2 发布说明

日期：2026-10-31

## 新增

- **真实文件索引**：扫描登记的工作区目录，SQLite 建索引（文件名/路径），新增 /api/search、/api/file、/api/index/start、/api/index/status；
- **网页搜索接真实索引**：搜索框、海拉「找/在哪」、DSH 插件 rc_hub_search 三处共用；
- **模型 API 设置**：DeepSeek / 豆包 / OpenAI / 自定义；Key 用 DPAPI 加密，界面不回显；「测试连接」；
- **海拉真聊天**：/api/chat + 人设卡（支持加密读取）；
- **插件 Client 半**：设置页「弧梦中枢」+ 右下角数字中枢圆（粒子环绕，点击启动中枢并打开）；
- **安装向导**：Windows 原生目录选择（数据目录 + 工作区目录多选）；
- **插件 Host**：状态 / 人设摘要 / 模式 / 检索 / 打开目录 + 锚点卡。

## 修复

- 本地文件（ile://）模式下的设置面板误导报错（现在会提示"需要中枢服务"并禁用模型按钮）；
- 圆环点击无法启动中枢（插件加载时自动拉起服务 + 助手 /hub/start 兜底）。

## 已知限制

- 索引不搜正文（FTS5 全文在 Roadmap）；
- 设置页暂无「重建索引」按钮（可 POST /api/index/start）；
- 客户端插件首次安装后需重启一次 DSH。
